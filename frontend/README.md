## Getting Started

1. Run `npm install`
2. Run `npm run dev`

## Deployment

Two simple deployment options are included below. Pick whichever fits your workflow.

1) Vercel (recommended — zero config)

- Create a Vercel account and link your GitHub repository.
- Vercel auto-detects Vite and will run `npm run build` and deploy the `dist` folder.

2) GitHub Pages (automatic via Actions)

- This repo includes a GitHub Actions workflow at `.github/workflows/deploy.yml`.
- The workflow runs on pushes to the `main` branch, runs `npm ci` then `npm run build`,
  and publishes the `dist` directory to GitHub Pages via `peaceiris/actions-gh-pages`.
- Make sure your repository's Pages settings are configured to use the `gh-pages` branch (the action will create it).

Notes:
- The Vite `base` is set to `./` in `vite.config.ts` to make the app work when served from a subpath (GitHub Pages).
- For Vercel, no extra config is necessary — just connect the repo and deploy.
